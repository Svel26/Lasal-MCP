## Core / Project

### `project.target_ip.set`

Performs a surgical edit of the station .lss connection and keeps any LASAL SCREEN LSEOnlineConfig.xml sidecar in sync. Other settings are preserved.

- **Aliases:** `set_target_ip`, `set_target`, `target_ip`, `set_ip`
- **Risk:** write
- **Confirmation:** not required
- **Project:** required
- **Async:** not supported
- **Dry run:** not supported
- **Tags:** `station`, `target`, `network`, `ip`, `lss`

**Hints**

- Specify at least one of ip, port or ssltls.

**Parameters**

| Param | Type | Required | Description |
|---|---|---|---|
| `station` | string | no | Station name, e.g. 'PLC' or 'HMI'. Omit when the solution has one station. |
| `ip` | string | no | New IP address, e.g. '192.168.1.100'. |
| `port` | string | no | New port. Default is unchanged; use '1954' for the standard online port. |
| `ssltls` | boolean | no | Enable or disable SSL/TLS. Omit to leave unchanged. |

**Example 1 — Point the PLC station at a new controller.**

```json
{
  "action": "project.target_ip.set",
  "params": {
    "station": "PLC",
    "ip": "192.168.1.100"
  }
}
```

**Example 2 — Enable TLS for the HMI connection.**

```json
{
  "action": "project.target_ip.set",
  "params": {
    "station": "HMI",
    "ssltls": true
  }
}
```

### `class2.bootdisk.create`

Create a CLASS 2 bootdisk or update stick.

- **Aliases:** `create_class2_bootdisk`, `create_bootdisk`
- **Risk:** deploy
- **Confirmation:** required (`confirm=true`)
- **Project:** required
- **Async:** supported
- **Dry run:** not supported
- **Tags:** `class2`, `bootdisk`, `update-stick`, `deploy`, `usb`

**Parameters**

| Param | Type | Required | Description |
|---|---|---|---|
| `lcp_path` | string | no | Absolute path to the .lcp file. Omit to use the currently selected project. |
| `output_path` | string | yes | Directory to write the bootdisk into (e.g. a prepared USB stick root). |
| `overwrite` | boolean | yes | Overwrite existing bootdisk content. Default true. |
| `all_lobs_in_one` | boolean | yes | Write all .lob files into a single file. |
| `platform` | enum: AUTO, ALL, ARM, X86 | yes | Target architecture: AUTO (project target), ALL, ARM or X86. Default AUTO. |
| `update_script` | enum: none, all, menu | yes | Update-tool script flavor (update-stick mode): none, all (runs every update) or menu. Default none. |
| `add_autoexec` | boolean | yes | Place an autoexec.lsl into the destination directory that starts the update script (update-stick mode). |
| `autoexec_file` | string | no | Path of a regular Autoexec.lsl to place on the PLC (update-stick mode). |
| `os_file` | string | no | LasalOS image (.lbi) to include (update-stick mode). |
| `visu_publish_folder` | string | no | VISUDesigner 'Publish' folder to bundle into the update (update-stick mode). |
| `lvd_runtime` | boolean | yes | When a VISUDesigner publish folder is set: also use its Runtime directory. Default true. |
| `use_active_connection_files` | boolean | yes | Use the project's active connection files (update-stick mode). Default true. |
| `add_multimaster_stations` | boolean | yes | Copy the MultiMaster Stations.txt into the destination (update-stick mode). Default true. |
| `mode` | enum: simple, update_stick | no | Bootdisk flavor. Default: update_stick when any of os_file/visu_publish_folder/autoexec_file/add_autoexec/update_script is used, otherwise simple. |
| `timeout_s` | integer | yes | Timeout in seconds. Default 300. |

**Example — Create a bootdisk at the root of drive E:.**

```json
{
  "action": "class2.bootdisk.create",
  "params": {
    "output_path": "E:\\"
  },
  "confirm": true
}
```
